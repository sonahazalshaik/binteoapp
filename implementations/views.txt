  │                                                        │

  │  <x-app-layout> ... </x-app-layout>                    │

  │                                                        │

  │                                                        │
  │  // View renders (via partials/notify.blade.php):      │

  │  // This is included in layouts/app.blade.php          │

  │                                                        │

  ┌─ PASSING DATA TO VIEWS ───────────────────────────────┐
  │                                                        │
  │  // Method 1: compact()                                │
  │  return view('path', compact('var1', 'var2'));         │
  │                                                        │
  │  // Method 2: with()                                   │
  │  return view('path')->with('key', $value);             │
  │                                                        │
  │  // Method 3: array_merge (common data pattern)        │
  │  $common = $this->settingService->getSeo();           │
  │  return view('path', array_merge($data, $common));    │
  │                                                        │
  └────────────────────────────────────────────────────────┘

══════════════════════════════════════════════════════════════
  ⚠  DO'S & DON'TS (VIEWS)
══════════════════════════════════════════════════════════════

  ✅ DO's:
  • Use activeTemplate() for ALL frontend view paths —
    this enables theme switching without code changes.
  • Use @extends('layouts.app') for public pages.
  • Use @extends('admin.layouts.master') or ('admin.layouts.app')
    for admin pages — master is Bootstrap, app is Tailwind.
  • Use @extends('layouts.guest') for login/register.
  • Include 'partials.notify' in layouts to show flash messages.
  • Use <x-app-layout> component syntax as alternative to @extends.
  • Pass $pageTitle to every view for the <title> tag.
  • Use compact() or array_merge() consistently for data passing.

  ❌ DON'Ts:
  • DON'T use activeTemplate() for admin views — admin path is fixed.
  • DON'T hardcode 'templates.basic.' — always use activeTemplate().
  • DON'T create new views outside templates/basic/ for frontend.
  • DON'T create new views outside admin/ for admin panel.
  • DON'T remove @include('partials.notify') from layouts — it
    renders all flash messages.
  • DON'T mix old Bootstrap admin layout (master) with new Tailwind
    layout (app) in the same controller group.
  • DON'T forget to pass variables to views — undefined variables
    will silently fail in Blade.
  • DON'T use dd() or dump() in views — remove debug before commit.

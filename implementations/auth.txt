══════════════════════════════════════════════════════════════
  ⚠  DO'S & DON'TS
══════════════════════════════════════════════════════════════

  ✅ DO's:
  • Keep existing Auth controllers as-is — they are Laravel
    Breeze scaffold and work perfectly.
  • Keep ApiAuthController at root (routes/api.php references it).
  • Use 'auth:sanctum' guard for API authentication.
  • Use 'admin' guard for admin authentication.

  ❌ DON'Ts:
  • DON'T modify or remove Auth controllers — they handle
    critical login/register/password-reset flows.
  • DON'T change the admin guard or marketplace auth middleware.
  • DON'T remove Sanctum — it's used by the Flutter app.
  • DON'T change session-based auth to token-based for web.
  • DON'T modify the Google OAuth callback URLs.

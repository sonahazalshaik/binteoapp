  1. MARKETPLACE MODULE OVERVIEW
══════════════════════════════════════════════════════════════

  The Marketplace is a talent discovery platform where creators
  (Actors, Influencers) connect with Investors/Producers.

  It has its own auth system, portfolio management, gallery,
  services, subscriptions, messaging, and admin management.

══════════════════════════════════════════════════════════════
  ⚠  DO'S & DON'TS
══════════════════════════════════════════════════════════════

  ✅ DO's:
  • Keep existing MarketPlaceController.php at root level —
    moving it will break ALL marketplace routes.
  • Keep existing Admin marketplace controllers in Admin/.
  • Use MarketPlaceService for new marketplace features.
  • Use MarketplaceAuth middleware for protected routes.

  ❌ DON'Ts:
  • DON'T rename MarketPlaceController — routes reference it.
  • DON'T delete the existing marketplace login/register flow.
  • DON'T change the marketplace session auth logic
    (it uses its own guard, not Laravel's default).
  • DON'T modify existing marketplace migration files.
  • DON'T remove existing portfolio image handling logic.

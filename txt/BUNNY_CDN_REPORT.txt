PART 3 - WHY DOES A 1.6 GB VIDEO BECOME 8-10 GB? (SIMPLE EXPLANATION)
================================================================================

When we upload a video, Bunny does not save just that one file. Like YouTube,
it automatically creates SEPARAL COPIES in different qualities:

   Original file kept           -> 1.60 GB   (a setting currently ON)
   Copy in 1080p (Full HD)      -> 1.50 GB
   Copy in 720p (HD)            -> 0.80 GB
   Copy in 480p                 -> 0.40 GB
   Copy in 360p                 -> 0.25 GB
   Copy in 240p                 -> 0.15 GB
   Small streaming pieces       -> 0.30 GB
   ---------------------------------------
   TOTAL STORED:                ~5.00 GB  (and can reach 8-10 GB)

WHY SO MANY COPIES? Because viewers have different internet speeds:
   - Fast Wi-Fi viewer        -> watches the sharp 1080p copy
   - Weak mobile data viewer  -> automatically gets smooth 360p copy
This auto-switching is exactly how YouTube works - it needs the copies.
So we should NOT delete all of them; we just remove the ones nobody uses
(like 1080p+ on short vertical reels), which cuts storage by 50%+.

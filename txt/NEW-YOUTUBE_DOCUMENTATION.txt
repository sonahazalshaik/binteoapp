## STEP 1 The Homepage (index.blade.php)
**Route:** `GET /` → Homepage controller
**Layout:** `<x-app-layout>` (Tailwind + Alpine.js based)

**Controller Logic Flow:**

1. **Route** → `routes/web.php:30` — `Route::get('/', [HomeController::class, 'index'])->name('home');`

2. **Controller** → `HomeController@index` (file: `app/Http/Controllers/Web/HomeController.php`, line 19-23):
   - Laravel's DI injects `HomeService` into the constructor automatically
   - `$this->homeService->getHomepageData($request)` is called, passing the raw request
   - The returned array is spread into `view('frontend.index', $data)`

3. **Service** → `HomeService::getHomepageData()` (file: `app/Services/Frontend/HomeService.php`, line 15-73):
   - This method runs 12+ independent queries to assemble the entire page payload:
   
   a) **Main Video Feed** (line 17-25): `Video::forUser()->where('is_premium', 0)->with(['user.channel', 'reports'])->inRandomOrder()->paginate(12)`. The `forUser()` scope filters: public + published + ready for guests; also includes user's own private/draft when logged in. The `is_premium = 0` ensures only free videos. If `?category=` param exists, filters by category slug.
   
   b) **Trending Videos** (line 27-37): Same scope + orders by `is_trending DESC`, then by a subquery counting view_logs in last 24hr (`daily_views`), then by total `views_count DESC`. Takes 20, shuffles, returns 12.
   
   c) **Featured Videos** (line 39-43): `where('is_featured', true)->latest()->take(12)`
   
   d) **Featured Channels** (line 45-50): `Channel::where('is_featured', 1)->with('user')->orderBy('is_trending', 'desc')->latest()->take(12)`
   
   e) **Reels** (line 52-56): `Reel::forUser()->with(['user.channel', 'reports'])->where('visibility', Status::PUBLIC)->latest()->take(12)`
   
   f) **Marketplace Profiles** (line 58-60): Three queries filtering `MarketPlace` by `type` (actor/influencer/investor) with `status = 1` and `is_featured = 1`, random order, take 10 each.
   
   g) **Banner Ads** (line 62-66): Four queries on `BannerAd`, one per slot (`slot1`-`slot4`), checking `status = 1` and date range `start_date <= now() <= end_date`.

4. **View** → `resources/views/frontend/index.blade.php` receives 12 compact variables: `videos`, `trendingVideos`, `featuredVideos`, `featuredChannels`, `reels`, `featuredActors`, `featuredInfluencers`, `featuredInvestors`, `slot1Banners`-`slot4Banners`.

5. **Infinite Scroll** → When user scrolls to bottom, JS fires GET to `/fetch-videos?page=N` → `HomeController@fetchVideos` → `HomeService::fetchVideos()` (line 133-166): File-cached for 30s with key `fetch_videos_{md5(page+category+q)}`. Returns rendered HTML of `video_card` partials + `has_more` boolean.

6. **Notifications API** → `HomeController@notifications` (line 26-34) returns JSON of latest 20 `UserNotification` records with `unread_count`. `readAllNotifications()` marks all as read.

This is the main landing page of the Binteo platform. It is a rich, multi-section page designed to immediately engage visitors with trending content, featured profiles, and reels.

**What the page contains from top to bottom:**

1. **Hero Welcome Section** — A full-width promotional banner saying "Welcome to Binteo" with an orange accent color (`#ff571a`). Three CTA buttons are prominently displayed:
   - "Upload Video" (orange filled button linking to `videos.create`)
   - "Create Reel" (outlined button linking to `reels.create`)
   - "Explore Marketplace" (outlined button linking to `marketplace.index`)
   - Background subtle orange glow effect and fade-in entrance animations

2. **Featured Videos Section** — If `$featuredVideos` has records, up to 4 featured video cards are shown in a responsive grid (1-4 columns based on screen width). Each uses the `partials.video_card` component.

3. **Interactive Tab Section** — Two tabs toggled via Alpine.js (`x-data="{ activeTab: 'trending' }"`):
   - **Trending Tab**: Shows `$trendingVideos` in a grid with a "View All Trending" CTA button. If empty, shows a dashed border placeholder message.
   - **Featured Profiles Tab**: Contains four auto-scrolling infinite carousels:
     - **Featured Channels**: Infinite scroll left, uses `channel_card_small` partial
     - **Top Actors**: Infinite scroll left, uses `creator_card_small` partial
     - **Top Influencers**: Infinite scroll right (reverse direction)
     - **Premium Investors**: Infinite scroll left
     - Each carousel has drag-to-scroll support (mouse + touch), auto-pause on hover, and a "Explore Profile Marketplace" CTA at the bottom
   - Each carousel uses Alpine.js `x-data` with animation loop via `requestAnimationFrame`

4. **Banner Slot 2** — Inline banner carousel (`banner_carousel` partial) shown if `$slot2Banners` exist

5. **Reels Section** (Orange-themed gradient background) — A horizontal carousel of up to 5 reels:
   - Each reel card is 9:16 aspect ratio, plays video on hover
   - Shows user avatar, channel name, title, engagement stats (likes, views, comments)
   - Three-dot options menu per reel
   - Age-restricted / reported reels show a gate overlay with "I Understand" button
   - "See All" card at the end linking to `reels.index`
   - Left/right navigation arrow buttons
   - Gradient fade edges on desktop

6. **Category Scroller** — Horizontal scrollable category pills. "All" is highlighted by default. Each category links to `category.show` with the category slug.

7. **Main Video Feed** — A responsive grid (1-4 columns) of video cards loaded from `$videos`. After the 8th video, banner slots 3 and 4 are inserted (if available) as a full-width row. Uses `video_card` partial.

8. **Infinite Scroll** — If `$videos->hasPages()`, an infinite scroll loader is rendered with a spinner ring and "Loading more videos..." text. A scroll sentinel div triggers AJAX pagination.

**Key Features:**
- Full Tailwind CSS with dark mode (`dark:` prefix)
- Alpine.js for tabs, carousels, hover play, options menu
- Material Symbols icon set
- Responsive design (mobile to desktop)
- Processing/optimizing state with video polling
- Age restriction / premium content gating
- Infinite scroll pagination with skeleton loader

## STEP 1 Video Show Page (videos/show.blade.php)
**Route:** `GET /videos/{video}/{playlist?}` → `VideoController@show` → `VideoService::show()`
**Layout:** `<x-app-layout>`
**Middleware:** `throttle_views`

**Controller Logic Flow — `VideoService::show()` (lines 33-218 of VideoService.php):**

**Step A: Video Resolution (line 39-47)**
- Queries `Video::with(['user.channel', 'categories', 'copyrightStrikes' => fn($q) => $q->where('status', 'active')])`
- If `$video` is numeric → `where('id', $video)`. If string → `where('slug', $video)`
- If not found → returns `['redirect' => route('home'), 'notify' => ['error', 'Video no longer available']]`
- Controller catches this and redirects

**Step B: Visibility Gate (line 49-53)**
- If `$video->visibility == Status::PRIVATE` AND (not logged in OR not owner) → `abort(403, 'This video is private.')`

**Step C: Copyright Strike Gate (line 55-58)**
- If video has active strikes OR uploader has >= 3 active strikes → `abort(403, 'Content unavailable due to copyright strike.')`

**Step D: Premium Access Check (line 60-72)**
- `$hasAccess` starts `true`. If `$video->is_premium`, set to `false`, then re-check:
  1. Owner or purchased → `$hasAccess = true`
  2. `pricing_tier == 2` (exclusive/OTT) + user has OTT access → true
  3. User has premium plan → true
- Otherwise view shows lock overlay with price

**Step E: Scheduled Content Gate (line 74-77)**
- Future `scheduled_at` + not owner → `$hasAccess = false`

**Step F: Age Restriction (line 79)**
- `$isAgeVerified = !$video->is_age_restricted || auth()->check()` — login required for 18+ content

**Step G: Video URL Resolution (line 81-86)**
- Bunny CDN + `bunny_status === 'ready'` → `$video->getPlayUrl()` (signed Bunny URL)
- Else if `hls_path` → `asset($video->hls_path)`
- Otherwise empty → placeholder shown

**Step H: Playlist Context (line 88-109)**
- `?list=watch-later` → loads user's Watch Later playlist with videos+reels
- `?list=liked` → creates ad-hoc playlist from user's liked videos
- Numeric → `Playlist::find($playlistId)` with eager-loaded videos+reels

**Step I: Comments (line 111-118)**
- `$video->comments()->whereNull('parent_id')->orderBy('is_pinned', 'desc')`
- Sort: `top` → `withCount('likes')->orderBy('likes_count', 'desc')`; default → `latest()`
- `take(20)` top-level, eager loads `user`, `replies.user`, `likes`

**Step J: Related Videos (line 120-149)**
- Base: `Video::published()->where('id', '!=', $video->id)->with('user.channel')`
- `filter=channel` → same uploader. `filter=related` → shared categories. Fills to 10 with latest if under 6.

**Step K: View Counting (line 176-210) — Critical Pattern**
- Uses `app()->terminating()` callback — response returns to browser FIRST, then count happens
- Increments `views_count`. If `impressions < views_count`, sets `impressions = views_count`, else increments
- If logged in: `ViewLog::updateOrCreate(['user_id', 'video_id'], ['updated_at' => now(), 'device' => $device, 'country' => $country])`
- Device detection via User-Agent regex (Desktop/Tablet/Mobile)
- Country via `getIpInfo()` helper

**Step L: Banner Ads (line 156-166)**
- All 4 banner slots, filtered by active date range, grouped by `slot`

**Data Returned (line 212-218):**
`compact('video', 'relatedVideos', 'userPlaylists', 'ad', 'reels', 'hasAccess', 'isAgeVerified', 'general', 'playlistData', 'slot1Banners', 'slot2Banners', 'slot3Banners', 'slot4Banners', 'videoPlayUrl')`

The main video player page — the primary content consumption view.

**What the page contains:**

1. **Video Player Area**:
   - Large video player with Bunny CDN or local video source
   - Auto-play, controls, fullscreen support
   - Premium/age-restricted content gating with lock overlay
   - Encoding progress overlay (circular SVG progress)
   - Scheduled premiere countdown display

2. **Video Metadata**:
   - Title prominently displayed
   - View count (formatted with K/M suffixes), upload date
   - Channel avatar + name (clickable to channel page)
   - Subscribe / Unsubscribe button with subscriber count
   - Three-dot options menu (Report, Share, Add to Playlist, Watch Later, Download)

3. **Action Buttons**:
   - Like / Unlike (with count, heart icon)
   - Dislike
   - Share button (with share modal/URL copy)
   - Download button (if enabled)
   - Save to Playlist button

4. **Description Section**:
   - Expandable description with "Show more" / "Show less"
   - Hashtags as clickable search links
   - Category and tags

5. **Comments Section**:
   - Comment count header
   - Comment form (for logged-in users) with emoji picker
   - Pinned comment at top (if any)
   - Comment feed using `comment_item` partial recursively
   - Sort options (Newest first, Oldest first, Top liked)

6. **Sidebar — Related Videos**:
   - Uses `related_videos` partial
   - Horizontal video cards with hover preview
